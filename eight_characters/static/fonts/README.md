# Fonts

## Noto Serif TC: the stem and branch characters

`NotoSerifTC-stems-branches.woff2` holds only the 22 characters of the ten
stems and twelve branches (甲乙丙丁戊己庚辛壬癸, 子丑寅卯辰巳午未申酉戌亥),
with the full weight axis (200–900) of the variable font. The chart draws those
characters in it; any other character falls through to the next font in the
stack.

- Source: Google Fonts, Noto Serif TC v36, subset by the Google Fonts CSS API:
  `https://fonts.googleapis.com/css2?family=Noto+Serif+TC:wght@200..900&text=甲乙丙丁戊己庚辛壬癸子丑寅卯辰巳午未申酉戌亥`
- Retrieved: 2026-09-25, unmodified.
